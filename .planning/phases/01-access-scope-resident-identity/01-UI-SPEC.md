## Spacing Scale

| Token | Value | Usage |
|-------|-------|-------|

| sm | 8px | Compact element spacing, table cell internals |
| md | 16px | Default form spacing, card internals |
| lg | 24px | Section padding, grouped settings blocks |
| xl | 32px | Layout gaps between primary panels |
| 2xl | 48px | Major section breaks, auth hero separation |
| 3xl | 64px | Page-level spacing for top-level public/auth layouts |

Exceptions: compact and icon-only controls must still preserve a 44px minimum touch target.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #FFFFFF | Background, main content surfaces, high-legibility reading areas |
| Secondary (30%) | #F5F5F5 | Cards, sidebar, muted panels, grouped admin tools, dense supporting surfaces |
| Accent (10%) | #262626 | Primary CTA, active nav item, current-step emphasis, authenticated-status emphasis |
| Destructive | #DC2626 | Destructive actions only |

Accent reserved for: primary submit actions, active navigation state, current context emphasis, and high-importance authenticated status indicators. Do not use accent as a decorative highlight for all interactive elements. The visual tone for this phase should feel operational and enterprise-like: sharper contrast, clearer grouping, tighter density, and stronger information hierarchy within the existing neutral shadcn system.

---

## Visual Hierarchy

Primary focal point by screen:
- Public dashboard: active billing-period collection summary card and its aggregate progress data dominate first view.
- Resident portal states: status or guidance card for inactive, unmapped, or mapping-pending access dominates first view before any secondary details.
- Resident settings: editable profile/preferences form dominates first view, with protected identity fields visible but clearly secondary and read-only.
- Admin/treasurer screens: role-scoped page heading and primary table or review queue dominate first view, with filters and supporting metadata subordinate.

Hierarchy order within a screen: status banner or dominant summary first, primary action second, supporting details third, audit or explanatory metadata last.
