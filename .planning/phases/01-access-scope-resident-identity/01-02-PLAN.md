| authenticated browser → protected routes | Client-side navigation must mirror backend authorization without weakening it |

| T-02-02 | E | Route guards | mitigate | Preserve `RequireAdminLike` and `RequireSuperAdmin` blocking logic so hidden nav is not the only control per D-05. |
| T-02-03 | I | Inactive/unmapped states | mitigate | Render explicit blocked/limited UI states instead of redirect loops that could confuse users into retrying privileged routes. |
