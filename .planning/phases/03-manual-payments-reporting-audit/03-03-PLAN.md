<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| treasurer/admin browser → report query/export actions | Untrusted filter inputs influence potentially sensitive finance dataset retrieval and export. |
| report generation action → `public.reports` metadata | Missing generation records reduces auditability of produced monthly/receipt outputs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-09 | I | `/admin/reports` datasets | mitigate | Reuse role-scoped access + RLS-backed queries only; avoid broad unrestricted table scans from client code. |
| T-03-10 | T | CSV/report output fidelity | mitigate | Derive CSV/output rows from shared typed query contracts and validate totals/status invariants in M09 SQL checks. |
| T-03-11 | R | Report generation audit trail | mitigate | Persist generation metadata in `public.reports` for each monthly/receipt output action with actor and timestamp. |
| T-03-12 | D | Large export requests | accept | Initial v1 volume is neighborhood-scale; accept low DoS risk while keeping paged queries and bounded export scopes. |
</threat_model>
