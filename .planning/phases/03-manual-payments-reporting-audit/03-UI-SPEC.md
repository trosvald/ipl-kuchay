## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, badge inset spacing |
| sm | 8px | Compact controls, form row gaps, stacked helper/error text |
| md | 16px | Default card gaps, input spacing, row action groups |
| lg | 24px | Section padding, card header-to-content separation |
| xl | 32px | Major card/grid gaps, report filter group spacing |
| 2xl | 48px | Major section breaks between resident/admin/report blocks |
| 3xl | 64px | Top-level page spacing on desktop |

Exceptions: minimum interactive target 44px for icon-only or compact click targets; table dense rows may remain visually compact but row actions must still expose 44px-tall buttons.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `oklch(1 0 0)` | App background, page canvas, primary content surfaces |
| Secondary (30%) | `oklch(0.97 0 0)` | Muted cards, table headers, filter bars, inactive tabs, informational panels |
| Accent (10%) | `oklch(0.205 0 0)` | Primary CTA, active tab/filter state, refresh/retry actions, reconciliation/freshness emphasis |
| Destructive | `oklch(0.577 0.245 27.325)` | Reject actions, inline errors, destructive confirmations only |

Accent reserved for: `Kirim Bukti Transfer`, `Setujui Pembayaran`, `Export CSV`, active pending/verified/rejected tab state, manual refresh/retry controls, and reconciliation warning CTA. Never use accent for all badges or all links.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | `Kirim Bukti Transfer` |
| Empty state heading | `Belum ada data pembayaran` |
| Empty state body | `Belum ada data untuk ditampilkan pada filter ini. Ubah filter atau refresh untuk melihat data terbaru.` |
| Error state | `Data belum berhasil dimuat. Coba refresh lagi. Jika masalah tetap muncul, periksa koneksi atau ulangi beberapa saat lagi.` |
| Destructive confirmation | `Tolak submission`: `Tolak submission ini? Warga akan melihat alasan penolakan dan perlu memperbaiki lalu mengirim ulang.` |

Additional locked copy rules: rejected resident states must show an inline actionable checklist in Indonesian with what went wrong, what to fix, and how to resubmit (source: Context D-02). Proof preview failures must show inline reason plus `Coba lagi` action, not generic-only feedback (source: Context D-06). Reporting surfaces must show `Terakhir diperbarui` plus manual refresh control (source: Context D-12/D-13).
