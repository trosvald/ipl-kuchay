  id uuid primary key default gen_random_uuid(),
  invoice_id uuid not null references public.invoices(id) on delete cascade,

  generated_by uuid references public.profiles(id),

```sql
create policy "reports_select_own_receipt_or_admin"
on public.reports for select
to authenticated
using (
  public.is_admin_like()
  or (
    report_type = 'receipt'
    and exists (
      select 1
      from public.kavling_residents kr
      where kr.kavling_id = reports.kavling_id
        and kr.profile_id = auth.uid()
        and kr.active = true
    )
  )
);
```

| finance browser input → `generate-report-output` | Untrusted request payload chooses which artifact is generated and which payment/receipt row is linked. |
| Edge Functions → `public.reports` + private storage | Privileged writes can expose another resident's receipt if linkage or metadata is wrong. |
| resident receipt/history queries → `payments` / `reports` | Resident-facing reads must stay inside RLS-safe, invoice-scoped data only. |
